The tool failed.
The agent stopped.

A schema can be valid and still hand the agent a terminal command, a silent payload, or “wait and retry.” mcp-lint marks that before a person does.

What a red mark means

  1. 04

    Name the tool

    A credential error has to say login, not “run npm login.” A rate limit has to name the call to repeat.

  2. 05

    Stay inside the protocol

    Terminal, config file, browser page. An agent limited to MCP tools cannot do those, and it will try anyway.

  3. 06

    Mark the destructive ones

    check warns when a delete, send, payment, or deploy tool has no destructiveHint, and errors when a read-only hint is a lie.

The name has to survive the client.

OpenAI rejects anything outside letters, digits, underscore, and hyphen, and it caps the name at 64 characters. Gemini also refuses a name that starts with a digit.

Every command

One CLI. Each command does one job. npm latest is 0.9.0, so these commands, including report, are what npx mcp-lint runs.

check
Lint a tools file, or look one directory down for tools.json, tools.yaml, tools.yml, mcp-tools.json, mcp-tools.yaml, and mcp-tools.yml. It skips node_modules and dot directories. It can also read a live tools/list over stdio, SSE, or streamable HTTP. It does not call a tool to discover it. --format is terminal, json, or markdown. JSON here is the diagnostic array, not the audit report. --installed reads Cursor, Claude (including projects.<path>.mcpServers in ~/.claude.json), and VS Code configs. Remote URLs are skipped unless --remote is set. --score uses quality-v2. Missing description or schema fields add no points. An empty tool list is unmeasured. Schema rules walk outputSchema the same way as inputSchema. A missing output schema is not an error. A repeated name, or the same name on two installed servers, is an error. Errors exit 1. A missing measurement is not a pass.
npx mcp-lint check tools.json
compat
Show which tools survive Claude, Cursor, Gemini, VS Code, Windsurf, Cline, OpenAI, and Continue. Each cell is measured or not_observed. A mark is not proof that a client accepts the schema.
npx mcp-lint compat tools.json
fix
Write only fixes classed safe. --dry-run also lists review and manual. Titles are not invented.
npx mcp-lint fix tools.json --dry-run
explain
Print one rule, why it exists, and whether it can be fixed.
npx mcp-lint explain openai/no-additional-properties
preflight
Score a proposed tool call against a policy file before it runs. The result is allow, allow_with_rewrite, require_approval, or deny. An unknown tool_type is denied. The score is a heuristic, not a guarantee.
npx mcp-lint preflight action.json --policy preflight.yml
recover
Score a recorded failure. A stdio probe lists tools and does not invoke them. The bench on this page calls the same function.
npx mcp-lint recover errors.json
snapshot
Save a live tool list as stable JSON. Commit it, then let diff fail the build when a later list gets worse.
npx mcp-lint snapshot -o tools.json --server stdio -- node server.js
diff
Exit 1 when the new file adds an error the old file did not have.
npx mcp-lint diff before.json after.json
init
Write .mcplintrc.json.
npx mcp-lint init
report
Write one tools file as terminal text, JSON, Markdown, SARIF 2.1.0, or an HTML file that stays on this machine. This is the audit report. npm latest 0.9.0 ships it. If the run has no schema errors, the report says: “No schema errors in this run. Recovery, preflight, and live inspection were not measured.”
npx mcp-lint report tools.json --format html --output report.html

The mcp-lint-server binary exposes list rules, explain, check, fix, preflight, and score recovery. SDK exports are ., ./preflight, ./recover, ./rules, ./loaders, ./fixer, ./mcp-server, and ./audit.

A tool that is fine for one picker can be illegal for another. check runs the shared rules and the client rules together. Windsurf and Cline have name and schema rules. Their config files are not scanned by --installed.

What 0.9.0 is not

  • It is not the 1.0 release.
  • Zed and OpenCode are not claimed.
  • There is no command for live resources/list or prompts/list.
  • It does not call a tool in order to discover it.
  • There is no account and no telemetry. The license is MIT. Check, recover, and preflight stay free.
  • The GitHub Action example is robert19001-cmyk/mcp-lint@v0.9.0. It installs npm latest 0.9.0, so sarif: true uploads when the workflow has security-events: write.

Run it on the schema you already have

  • npx mcp-lint
  • npx mcp-lint recover errors.json
  • npx mcp-lint preflight action.json --policy preflight.yml

Copy uses the commands in the list above. With tools.json in the repo, the published Action needs no path. Pass recover when you have a failure file.
